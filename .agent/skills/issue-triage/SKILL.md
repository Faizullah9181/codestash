# Triage

Process an issue through the triage state machine. The output is a label change + an issue comment explaining the decision.

Every comment you post during triage **must start with**:

> *This was generated by AI during triage.*

This is non-negotiable. Don't omit it, abbreviate it, or move it.

## 1. Gather context

Read:
- `docs/agents/issue-tracker.md` — how to read and update the issue
- `docs/agents/triage-labels.md` — the label strings for this repo
- `docs/agents/domain.md` — then `CONTEXT.md` and `docs/adr/`
- `.out-of-scope/` — see [OUT-OF-SCOPE.md](OUT-OF-SCOPE.md)

Fetch the issue to triage. Read it and all existing comments.

## 2. State machine

```
              needs-triage
                   │
        ┌──────────┼──────────┐
        │          │          │
   out of scope  needs-info  in scope
        │          │          │
    wontfix    (wait for    classify
                 reply)
                             │
                    ┌────────┴────────┐
                    │                 │
                   bug          enhancement
                    │                 │
               fully spec?       fully spec?
                    │                 │
               ┌────┴────┐       ┌────┴────┐
               │         │       │         │
         ready-for-   ready-  ready-for-  ready-
           agent     for-human  agent    for-human
```

### Decisions to make

**Is it in scope?**
Check `.out-of-scope/` and your domain knowledge. If out of scope, apply `wontfix`, explain why in the comment, and reference the relevant `.out-of-scope/` file if one exists.

**Is it a bug or enhancement?**
- Bug: a deviation from documented behaviour or clearly broken functionality
- Enhancement: new capability, changed behaviour, or improvement

**Is it fully specified?**
An issue is fully specified (ready for an agent) when it satisfies the AGENT-BRIEF spec — see [AGENT-BRIEF.md](AGENT-BRIEF.md). If not fully specified:
- If the gap is something the reporter can fill in: apply `needs-info`, comment asking the specific question(s)
- If the gap requires a human judgment call that can't be delegated: apply `ready-for-human`

**Rewrite to AGENT-BRIEF spec:**
If the issue is fully specifiable, rewrite it (or post a comment with the rewritten spec) using the template in [AGENT-BRIEF.md](AGENT-BRIEF.md), then apply `ready-for-agent`.

## 3. Output

Post one comment (starting with the disclosure note) that:
- States the classification (bug/enhancement, in/out of scope)
- Explains the decision in 2–4 sentences
- If `needs-info`: asks the specific question(s) needed
- If `ready-for-agent`: includes the full AGENT-BRIEF rewrite
- If `wontfix`: references `.out-of-scope/` if applicable

Then apply the label.
